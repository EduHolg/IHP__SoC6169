# Full-chip transient testbench (Spectre)

| File | Description |
|---|---|
| `input.scs` | Main netlist (generated by Virtuoso from `CAMPROYECT/COMPLETE_PROYECT_TB`): analog subcircuits, chip top `COMPLETE_PROYECT_FIG` (with the V_EVAL driver), VDD = 1.2 V, VEVAL_IN = 0.5 V, CLK 100 MHz (first rising edge at 5 ns), `tran` 0–3400 ns, TT, 27 °C |
| `inputs.scs` | Simulator options (`duplicate_subckt=warning`) |
| `digital_blocks.spice` | Netlists of the 6 digital blocks with their sg13g2 cells (taken from `netlist/schematic/COMPLETE_PROYECT_FIG_lvs.spice`) |
| `vec/ctrl_in6.spice` | `reset` and `EN_WRITE` / `EN_REFERENCE` / `EN_SEARCH` pulses |
| `vec/ser_in6_ref19.spice` | `serial_in_addr` and `serial_in_data` streams |

Before running, edit the model include in `input.scs` to point to your installation of the lv MOS models (the same files are used by SG13G2 and SG13CMOS5L):

```
include "<PDK>/tech/SG13_MOS/library/spectreG2/cornerMOSlv_psp.scs" section=tt
```

Run: `spectre input.scs`

## Test sequence

| Operation | EN (ns) | Word | Address | HD to query |
|---|---|---|---|---|
| Write row 0 | 30–50 | 0x0000FFFF | 00000 | 0 |
| Write row 5 | 400–420 | 0x0000E000 | 00101 | 13 |
| Write row 13 | 770–790 | 0x00FF01FF | 01101 | 15 |
| Write row 20 | 1140–1160 | 0x00FF00FF | 10100 | 16 |
| Write row 22 | 1510–1530 | 0x00030000 | 10110 | 18 |
| Write row 31 | 1880–1900 | 0xFFFF0000 | 11111 | 32 |
| Reference | 2250–2270 | 0xFFF8FFFF | — | 19 vs 0xFFFF0000 |
| Search | 2620–2640 | 0x0000FFFF | — | — |

Expected: COMP0 = COMP5 = COMP13 = 0 (match), COMP20 = COMP22 = COMP31 = 1 (mismatch); capture ≈ 2.958 µs, serial read-out on `OUTPUT` ≈ 3.00–3.31 µs (row 31 first).

Note: the original testbench included the six per-block netlists `CAMPROYECT/<block>/spiceText/spice.spc`; here they are replaced by `digital_blocks.spice`.
